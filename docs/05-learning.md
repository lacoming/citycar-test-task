# 5. Чему научился самостоятельно за последние полгода

[← 4. AI-проект](04-ai-project.md) · [README](../README.md) · [6. Улучшение →](06-improvement.md)

Формат: навык → где применил → что получилось.

### 1. Делить работу между кодом и моделью

- **Навык.** Цифры, вердикты и проверки считает детерминированный код. Модель отвечает только за смысл и текст, а её ответ проверяется схемой и правилами.
- **Где применил.** В системе квалификации клиентов ([раздел 4](04-ai-project.md)) вердикт считается без ИИ, а письмо от модели проверяет код. Архитектура для CityCar построена так же.
- **Что получилось.** Модель не может исказить вердикт, потому что не она его считает. Пересчёт всей базы стоит ноль рублей, поэтому пороги калибруются десятками прогонов подряд.

### 2. Мультиагентные системы с границами ответственности

- **Навык.** У каждого агента одна роль, свои инструменты и явная граница: что он делает сам, а что отдаёт человеку. Хуки подгружают контекст в каждую сессию автоматически.
- **Где применил.** В рабочей среде на Claude Code: планирование, проверка кода, проверка безопасности и тексты клиенту выполняют отдельные агенты.
- **Что получилось.** Веду шесть клиентских проектов одновременно в одиночку. Проверка безопасности запускается сама, когда правка касается авторизации, загрузок, вебхуков или миграций.

### 3. Работа с недоверенным вводом для LLM

- **Навык.** Текст с чужих сайтов, из писем или звонков - это данные, а не инструкции. Такой текст изолируется разделителями, а агент, который его читает, не получает инструментов с побочными эффектами.
- **Где применил.** В аудиторе сайтов: тексты страниц попадают к модели только как отделённые недоверенные данные.
- **Что получилось.** Тот же приём заложен в разбор звонков для CityCar ([раздел 2](02-automation-and-risks.md#безопасность-контура)).

### 4. Реклама через API: Яндекс Директ и Метрика

- **Навык.** Выгрузка статистики и поисковых запросов, разбор, куда уходит бюджет, план правок в машинно-исполнимом виде («объект, поле, было → станет»).
- **Где применил.** Рекламная кампания клиента, нулевая конверсия.
- **Что получилось.** Нашёл причину: нецелевой трафик и переоценённый спрос ниши. Слив бюджета остановлен.
